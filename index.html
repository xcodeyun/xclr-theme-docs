Xclr theme documentation

Xclr is an editorial apparel theme for Shopify Online Store 2.0. This guide covers installation, theme settings, sections, and support.

    Logo, fonts, colors, layout, and menus.

Requirements

  • A Shopify store with the Online Store channel.
  • No apps are required. No build step is needed — the theme runs as uploaded.
  • A logo and a favicon are optional, but recommended before you publish.

Install the theme

  1. Obtain the theme .zip file.
  2. In the Shopify admin, go to Online Store → Themes.
  3. Click Add theme → Upload zip file and select the file.
  4. Preview the theme, then click Publish when you are ready to make it live.

Set up your store

  1. Upload your logo and favicon, and set the logo width in Theme settings → Branding.
  2. Choose a primary font in Theme settings → Typography.
  3. Set your background, foreground, and accent colors in Theme settings → Colors.
  4. Adjust page width and page margin in Theme settings → Layout.
  5. Create a main menu and a footer menu under Online Store → Navigation. The theme uses the main-menu and footer menus by default.
  6. Open the theme editor and build the home page from sections: Hero banner, Featured collection, and Image with text.

Updating the theme

When a new version of Xclr is available, upload the new .zip file as a separate theme, preview it, and publish it when you are satisfied. Theme updates replace the theme code, so keep custom code changes in a separate copy or in the Custom liquid section so they are easy to re-apply.

Before you publish: check the home page, product pages, collection pages, search, and the cart at both mobile and desktop widths. If something looks wrong, contact support with your store URL and a screenshot.
