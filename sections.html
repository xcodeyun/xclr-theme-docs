Sections

Add, remove, and reorder sections in the theme editor. Each section below can be added to any page that supports sections.

Hero banner

A full-width image banner with optional text and a button. The heading is rendered as the page's main heading.

SettingWhat it does
ImageBackground image, cropped to fill the banner. Recommended 2400 × 1600 px or larger.
Eyebrow textSmall uppercase label above the heading.
HeadingMain banner headline.
TextShort supporting paragraph.
Button labelCall-to-action text. The button is hidden when the label or link is empty.
Button linkWhere the button goes.
Overlay opacityDark overlay behind the text, from 0% to 80%. The default is 30%.
HeightSmall, Medium, or Large. Height changes with the screen size.
Content positionLeft, Center, or Right.

Featured collection

A grid of products from one collection. Product cards use a 3:4 image ratio and show the price, a compare-at price when present, and a sold-out label.

SettingWhat it does
CollectionThe collection to show. The section is empty until a collection is selected.
Eyebrow textSmall uppercase label above the heading.
HeadingSection title.
Products to showBetween 2 and 12 products. The default is 8.
Show view all linkAdds a link to the full collection.

The grid uses 2 columns on phones, 3 columns from 750 px, and 4 columns from 1176 px.

Image with text

An image beside a block of text. The two columns sit side by side from 990 px and stack below that.

SettingWhat it does
ImageCropped to a 4:5 portrait ratio. Recommended 1600 px wide or larger.
Image positionPlaces the image on the Left or Right of the text.
Eyebrow textSmall uppercase label above the heading.
HeadingSection title.
TextSupporting paragraph.
Button labelCall-to-action text.
Button linkWhere the button goes.
BackgroundAccent uses your accent colors; Plain uses the page background.

Product

The main product section. Every part of the product page is a block, so blocks can be reordered, removed, or added — including app blocks and custom liquid blocks.

BlockWhat it does
TitleThe product title, rendered as the page heading.
VendorLinks to all products from the same vendor.
PriceThe price, a compare-at price when present, and a sold-out label.
DescriptionThe product description as rich text.
Buy buttonsVariant picker, quantity, add to cart, and an optional payment button.
Custom liquidFree-form Liquid or HTML, for app snippets and small customizations.
App blockBlocks added by installed apps, placed anywhere among the other blocks.

Featured product

Highlights a single product with its image and content. It is built from blocks the same way as the Product section, and supports app blocks and custom liquid blocks.

SettingWhat it does
ProductThe product to highlight. The section stays empty until a product is selected.

Blocks: title, price, description, button, custom liquid, and app blocks.

Custom liquid

Paste Liquid or HTML directly into the section. Use it for small snippets, embeds, or app snippets that output Liquid. The section is hidden when the field is empty. A Custom liquid block with the same liquid setting is also available inside the Product, Featured product, and Custom section blocks.

Custom section

A full-width section with an optional background image and nestable blocks. Use it to compose layouts from text and group blocks without adding code.

Header and footer

The header and footer are section groups. Open them in the theme editor to add or remove sections and rearrange their content. Every page uses the same header and footer.
