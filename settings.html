Theme settings

Global settings apply to every page. Open the theme editor, then click the settings icon next to the theme name to edit them.

Branding

SettingWhat it does
LogoReplaces the store name in the header. Use a horizontal image on a transparent background.
Logo widthSets the logo width from 60 px to 240 px. The default is 120 px.
FaviconThe small icon shown in browser tabs and bookmarks. Use a square image; 48 px or larger is recommended.

Typography

SettingWhat it does
PrimaryThe font used for headings and body text. Pick any font from Shopify's font library. The theme loads regular, bold, italic, and bold italic variants automatically.

The default font is Work Sans. Headings scale fluidly between screen sizes; no extra font settings are needed.

Layout

SettingWhat it does
Page widthNarrow (90rem) or Wide (110rem). This is the maximum width of page content on large screens.
Page marginThe minimum space between page content and the screen edge, from 10 px to 100 px. The default is 20 px.

Colors

SettingWhat it does
BackgroundThe page background color.
ForegroundThe default text and button color.
Accent colors: BackgroundUsed by sections that offer an accent background, such as Image with text, and by image placeholders.
Accent colors: ForegroundThe text color on accent backgrounds.
Input corner radiusRounds the corners of form fields, from 0 px to 10 px.

Keep the foreground color readable against the background color. Check both pairs — the main colors and the accent colors — before publishing.

Header and footer

SettingWhat it does
Header: MenuThe menu shown in the header. Defaults to main-menu.
Footer: MenuThe menu shown in the footer. Defaults to footer.
Footer: Show payment iconsShows the payment icons enabled in your store's payment settings.

Responsive behavior

The theme adapts at three breakpoints:

  • Below 750 px — single column layouts, 2 product columns, taller hero.
  • 750 px to 989 px — 3 product columns, side-by-side content where space allows.
  • 990 px to 1175 px — 3 product columns, split layouts such as Image with text.
  • 1176 px and above — 4 product columns and the widest content area.
