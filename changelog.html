Changelog

Release notes for the Xclr theme and this documentation.

0.1.0 — 2026-10-17

Initial release.

  • Online Store 2.0 templates: home, product, collection, collection list, cart, search, blog, article, page, 404, password, and gift card.
  • Theme settings for branding (logo, logo width, favicon), typography, layout (page width, page margin), colors (background, foreground, accent background, accent foreground, input corner radius).
  • Sections: Hero banner, Featured collection, Image with text, Custom liquid, Custom section, plus the default template sections.
  • Header and footer section groups with logo support, menus, and payment icons.
  • Responsive product grid: 2 columns on phones, 3 columns from 750 px, 4 columns from 1176 px.
  • Product cards with compare-at price and sold-out state.
  • Responsive images with generated sizes, lazy loading below the first viewport, and eager loading for the hero and first product images.
  • Documentation site (this site).
